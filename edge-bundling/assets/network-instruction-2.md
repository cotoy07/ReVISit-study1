# 研究概要：エッジバンドリング前後におけるネットワーク図の可読性評価

## 1. 背景
ネットワーク図とは「点（ノード）」と「それらをつなぐ線（エッジ）」でモノや人のつながりを表した図であり、データの関係性を理解するために様々な分野で利用されています。

しかし、データの規模が大きくなると図が混み合い、読み取りが難しくなることがあります。その解決策として、複数の線を束ねて視覚的な複雑さを低減する「**エッジバンドリング**」という手法が使われます。

一方で、エッジバンドリングは特定のタスクにおいて逆効果となる場合もあり、全ての場面で有用であるとは限りません。

## 2. 研究の目的
本研究では、以下の要素のどの組み合わせにおいてエッジバンドリングが高い可読性を発揮するかを分析し、適切な条件を明らかにすることを目的とします。
- ネットワークの種類
- 密度や規模
- ユーザーのタスク

本研究のアンケート調査では、エッジバンドリング前後の図を比較し、以下の3つの観点から**可読性**を評価します。

### 可読性の定義
1. **情報の得やすさ**：関係性や全体構造（グループ同士の繋がりなど）を把握しやすいか。
2. **見やすさ**：ノードやエッジが判別しやすいか。特定の線を正確に追えるか。
3. **美しさ**：視覚的に好ましい・心地よいと感じるか。

## 3. 実験の手順
実験は以下の手順で行われます。

1. **比較**: 画面の左右に提示される2つのネットワーク図（エッジバンドリング適用前と適用後）を比較します。
2. **選択**: 上記3つの評価観点それぞれについて、「どちらが優れているか（あるいは同等か）」を選択します。
3. **試行**: 全部で **63セット** の比較を行います。
